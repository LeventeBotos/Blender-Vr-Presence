# Blender VR Add-on: Simple VR Tools

This Blender add-on adds simple **VR navigation controls** for exploring your scenes with **OpenXR**.

## Features
- Start/stop VR sessions
- Step forward in VR space
- Rotate left/right
- Reset position to a default "standing" pose

## Installation
1. Download this repository as a `.zip`
2. In Blender: `Edit > Preferences > Add-ons > Install...`
3. Select the zip file
4. Enable **Simple VR Tools**

## Usage
- Open `3D View > Sidebar > VR`
- Use the buttons to move, turn, and reset position while in VR mode.

## Requirements
- Blender 3.0+
- OpenXR runtime installed
